# Frontend Mentor - QR code component solution

This is a solution to the [QR code component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H). Frontend Mentor challenges help you improve your coding skills by building realistic projects. 

## Overview

![Screenshot of Application](images/QRCode.png)

The component is a card with a QR code, a short heading and a description text. The challenge focuses on:

- writing semantic HTML, using elements that fit the content
- paying attention to detail to match the design (colors, fonts, spacing)

## Built with

- HTML5
- CSS3

## What I learned

- Choosing semantic elements instead of generic `div`s
- Translating a design into CSS, using the provided style guide for colors and fonts
